# Year 2 Winter Decision Tool

A small decision tool for the Pork and Garlic Ice Cream Co. classroom simulation.

## Before using it

Replace the yellow Year 1 starting-position fields with your team’s real Year 1 autumn figures. Add every owned machine and its remaining life. The values currently in the tool are starter estimates, not confirmed Year 2 rules.

## How to use it

1. Enter a possible Year 2 winter plan in each option.
2. Enter a possible trainer sales allocation rather than assuming the full request will sell.
3. Read the profit, cash-flow, capacity, and negative-cash warnings.
4. Temporarily make Option A match one real Year 1 season and compare it with your classroom net profit and closing cash.
5. Choose a recommendation and state the assumption that makes it work.

## Publish

Push this repository to GitHub, import it in Vercel, deploy, then add the live Vercel and GitHub links only to your own assigned row in the class submission spreadsheet.
